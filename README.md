# Mario All-Stars + World Split Recomp

[Download the latest release](https://github.com/Bentley734/Mario-All-Stars-World-Split-Recomp/releases/latest)

This desktop edition of [Mario All-Stars + World Recomp](https://github.com/Bentley734/Mario-All-Stars-World-Recomp) gives each of the five games its own app or executable.

- Super Mario Bros.
- Super Mario Bros.: The Lost Levels
- Super Mario Bros. 2
- Super Mario Bros. 3
- Super Mario World

## Play

1. Download the Windows x64 or Apple silicon macOS ZIP from Releases and extract it.
2. Open the game you want. When prompted, select your own USA Super Mario All-Stars + Super Mario World combination cartridge dump. The ZIP does not include the ROM.
3. Each launcher opens its own title screen with File A selected. Use the included collection app to select a different save file. The launchers share the same cartridge path, saves and settings. Close one game before opening another.

Open the in-game menu with Escape or Start + Select on a mapped controller. It includes controls, cheats and display settings. The 32:9 option is marked **Experimental**.

The included RecompLauncher profile provides a separate tile for each title on RecompLauncher 0.90 Beta 36 and later.
